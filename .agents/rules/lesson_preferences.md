# Lesson Generation Rules for 10-Year-Old Kids (Uzbek)

- **Target Audience**: 10-year-old children.
- **Language**: Uzbek (O'zbek tili).
- **Structure**: Each lesson in its own folder (`lesson1`, `lesson2`, etc.) containing `index.html`, `style.css`, and `script.js`.
- **Mascot**: "Kodi" (cheerful robot guide).

## 📅 Official 6-Lesson Course Roadmap
1. **Lesson 1** (Done): HTML Core Tags (`h1-h6`, `p`, `button`, `img`, `a`, `ul/li`, `strong`).
2. **Lesson 2**: HTML Complete: Containers & Forms (`div`, `span`, `input`, `audio`, `video`, `form`). HTML finished!
3. **Lesson 3**: CSS Colors & Box Model (`color`, `background`, `font`, `margin`, `padding`, `border`).
4. **Lesson 4**: Flexbox Magic (arranging items, cards, responsive layout).
5. **Lesson 5**: Motion & Animations (hover effects, transitions, CSS keyframe animations).
6. **Lesson 6**: Capstone Project: Real Kid's Website from scratch.

- **Standard Modules in Every Lesson**:
  1. Concept Introduction (Lego/everyday analogies).
  2. Interactive Explorer (tags/code live animation).
  3. Interactive Playground ("O'zing Sinab Ko'r").
  4. Mini-Quiz with stars, sound effects, and confetti.
- **Audio**: Pure Web Audio API synthesizers (no external MP3/WAV files).
- **Performance & Tokens**: Present proposals/plans concisely and avoid unnecessary background video recordings.
